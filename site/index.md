# NearBird

**Chat with people nearby, without the Internet.** NearBird is a free Android
messenger that sends messages phone-to-phone over Bluetooth. Messages can hop
through other NearBird phones to reach people further away. No account, no
phone number, no servers. Internet features are optional and off by default.

## Download

Get the latest version from **[GitHub Releases](https://github.com/Rohanr1904/nearbird/releases/latest)**.

| File | Use it for |
|---|---|
| `nearbird-arm64.apk` | Almost all phones from the last several years |
| `nearbird-universal.apk` | Any phone, if the file above does not install |
| `nearbird-wear.apk` | Wear OS watches (optional) |

NearBird is not on the Play Store. To install it:

1. Download the APK on your phone and open it.
2. If Android asks, allow your browser or file app to **install unknown apps**.
3. If Play Protect warns about an unknown app, choose **More details → Install anyway**.

NearBird checks GitHub for new versions only if you turn Internet features on.

## Check that your download is genuine

Every official APK is signed with the NearBird release key. Its SHA-256
certificate fingerprint is:

```
CA:84:57:E5:06:D2:E9:D5:40:29:85:CC:4F:0B:60:2E:99:33:D3:1A:C1:47:3E:6D:05:A5:48:2B:72:2C:83:B1
```

Each release also lists SHA-256 checksums (`NEARBIRD_SHA256SUMS`) and GitHub
build attestations. See
[reproducible builds](https://github.com/Rohanr1904/nearbird/blob/main/docs/reproducible-builds.md).

## Privacy

Read the **[privacy policy](privacy/)**. In short: your messages and keys stay
on your phones, and the developer receives no data.
