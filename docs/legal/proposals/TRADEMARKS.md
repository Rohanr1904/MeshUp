## What the licence does and does not give you

NearBird's source code is licensed under the GNU General Public License v3.0 (`LICENSE.md`). You may copy, modify and redistribute it under those terms.

Under GPLv3 section 7(e), the licence **does not grant any right to use trade names, trademarks or service marks**. The names and logos below are therefore **not** licensed to you, even though the code is.

## Covered marks

- the name "NearBird" (including "Near Bird", "Nearbird" and confusingly similar names);
- the project handle `nearbirdapp` on social platforms and, if created later, as a GitHub organisation. (The bare handle "nearbird" is already taken by unrelated parties on GitHub, X, Mastodon and Instagram, so `nearbirdapp` is the project handle; the repository stays at github.com/Rohanr1904 because the app ID depends on that account.)
- the NearBird app icon and logo, and the NearBird bird artwork [owner to confirm the exact list once the icon exists];
- the app ID `io.github.rohanr1904.nearbird` and the official download pages and release signing certificate, as indications of the official build.

## What you may do without asking

- Build the unmodified source and use the result yourself.
- Redistribute an **unmodified**, official NearBird release file as published on the project's GitHub Releases page, with its signature intact.
- Describe the project accurately (for example, "a fork of NearBird", "compatible with NearBird", "based on the NearBird source code").
- Link to the repository and use the name in reviews, articles and discussions.

## What you must do if you modify NearBird

If you distribute a modified version (a fork), the GPL lets you do that, and you must:

1. **Rename it.** Use a clearly different app name, app ID (applicationId), icon and logo.
2. **Not use the NearBird name or logo** in a way that suggests your build is the official one or is endorsed by the NearBird maintainers.
3. **Sign it with your own key**, and not describe it as an official release.
4. Keep the GPLv3 notices, the upstream attribution in `NOTICE`, and your own dated modification notices (GPLv3 section 5(a)).

## Why this exists

NearBird is a security-sensitive messenger. People should be able to tell the genuine app from a look-alike that might, for example, weaken encryption or collect data. This policy restricts only the name and logo, not your rights to the code.
